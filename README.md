# IT Solutions & Services Web Platform

A modern, responsive, and high-performance IT Solutions & Digital Services website built with **React 19**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

---

## ✨ Features

- 🚀 **Modern Tech Stack**: React 19, Vite, Tailwind CSS v4, Lucide Icons, and Framer Motion animations.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile displays.
- 🎨 **Sleek UI/UX**: Interactive hero sections, micro-interactions, gradient themes, and clean typography.
- 📑 **Comprehensive Pages**:
  - **Home**: Dynamic hero, statistics, featured services, client reviews, tech stack, and CTA.
  - **Services**: Detailed breakdown of IT solutions, cloud architectures, cybersecurity, and web development.
  - **About Us**: Company vision, journey, mission, and core values.
  - **Team**: Leadership and core engineering talent showcase.
  - **How We Work**: Transparent development process and methodologies.
  - **Careers**: Open positions, company culture, and application workflow.
  - **Blog & Insights**: Technology articles and industry trends with dedicated blog detail views.
  - **FAQ**: Searchable and categorized frequent questions with interactive accordions.
  - **Contact**: Interactive contact form, office locations, and quote request modal.

---

## 🛠️ Tech Stack

- **Frontend Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Routing**: [React Router](https://reactrouter.com/)

## 🚀 Getting Started

### Prerequisites

- Node.js (version 18 or higher)
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/rishigoswami7773/It_web.git
   cd It_web
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

5. **Preview production build**:
   ```bash
   npm run preview
   ```
